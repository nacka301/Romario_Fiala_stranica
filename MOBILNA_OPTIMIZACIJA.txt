==========================================
MOBILNA OPTIMIZACIJA - ŠTO JE IMPLEMENTIRANO
==========================================

✅ PRAVILO 1: JEDNOKOLONSKI LAYOUT
-----------------------------------
• Sve sekcije na mobitelu postavljene u 1 kolonu
• Nema više grid-a - sve vertical
• Gallery: 1 slika po redu (čitljivo i jasno)
• Services: kartice jedna ispod druge
• Contact forma: lijevo-desno postaje gore-dolje

Gdje implementirano:
- .about-content { grid-template-columns: 1fr; }
- .services-grid { flex-direction: column; }
- .gallery-grid { grid-template-columns: 1fr; }
- .contact-wrapper { grid-template-columns: 1fr; }

-----------------------------------

✅ PRAVILO 2: VEĆI TEKST
-----------------------------------
• H1 (Hero naslov): 24-28px
• H2 (Sekcije): 24-26px
• H3 (Usluge): 20-22px
• Normalni tekst: 16px (MINIMUM)
• Podnaslov: 16-18px

Gdje implementirano:
- .hero-title { font-size: 28px !important; } @ 768px
- .hero-title { font-size: 24px !important; } @ 480px
- .section-title { font-size: 26px; } @ 768px
- body { font-size: 16px; } (globalno)
- .service-card p { font-size: 16px; }

-----------------------------------

✅ PRAVILO 3: VELIKE KLIKABILNE TIPKE
-----------------------------------
• Minimalna visina: 52-56px (veće od 44px standarda)
• Puna širina na mobitelu (100%)
• Velike touch zone za lakše klikanje
• Kontrast boja (braon na bijelo)

Gdje implementirano:
- .btn { min-height: 56px !important; } @ 768px
- .btn { min-height: 52px !important; } @ 480px
- .btn { width: 100%; } na mobitelu
- .nav-link { padding: 16px 20px; } (44px+ visina)

-----------------------------------

✅ PRAVILO 4: RAZMACI IZMEĐU ELEMENATA
-----------------------------------
• Container padding: 20px sa strana (768px)
• Container padding: 16px sa strana (480px)
• Gap između kartica: 24px
• Margin između form grupa: 24px
• Section padding: 48px (gore-dolje)

Gdje implementirano:
- .container { padding: 0 20px; } @ 768px
- .container { padding: 0 16px; } @ 480px
- .services-grid { gap: 24px; }
- .form-group { margin-bottom: 24px; }

-----------------------------------

✅ PRAVILO 5: SLIKE 100% ŠIRINE
-----------------------------------
• Sve slike skaliraju na punu širinu
• aspect-ratio zadržan (nema deformacije)
• border-radius za ljepši izgled

Gdje implementirano:
- .about-image img { width: 100%; height: auto; }
- .gallery-item { width: 100%; }
- .gallery-item img { width: 100%; height: auto; }
- img { max-width: 100%; height: auto; } (globalno)

-----------------------------------

✅ PRAVILO 6: HAMBURGER MENI
-----------------------------------
• Hamburger ikona gore desno
• Slide-in meni sa lijeva
• Centirrani linkovi
• Velike touch zone (44px+)
• z-index: 999 (uvijek na vrhu)

Gdje implementirano:
- .nav-toggle { display: flex; } @ 768px
- .nav-menu { position: fixed; left: -100%; }
- .nav-menu.active { left: 0; }
- .nav-link { padding: 16px 20px; font-size: 18px; }

-----------------------------------

✅ PRAVILO 7: JEDNA GLAVNA AKCIJA
-----------------------------------
• Samo JEDNO dugme u hero: "Kontaktirajte nas"
• "Nazovi odmah" dugme uklonjeno (po zahtjevu)
• Fokus na jedan jasan call-to-action

Gdje implementirano:
- Uklonjeno "Nazovi odmah" dugme iz HTML-a
- Ostavljen samo jedan btn u hero sekciji
- CTA vidljiv i jasan

-----------------------------------

✅ PRAVILO 8: JAK KONTRAST
-----------------------------------
• Bijela pozadina + tamni tekst (#1a1a1a)
• Braon buttoni (#8B4513) sa bijelim tekstom
• Bez sivog na sivo efekta
• Font smoothing za bolju čitljivost

Gdje implementirano:
- body { color: #1a1a1a; background: #ffffff; }
- -webkit-font-smoothing: antialiased;
- .btn-primary { background: #8B4513; color: white; }
- Svi kontrastni odnosi > 4.5:1 (WCAG AA standard)

-----------------------------------

✅ PRAVILO 9: BRZINA UČITAVANJA
-----------------------------------
• Lazy loading za slike (loading="lazy")
• Minimalne animacije
• Touch action optimizacija
• CSS transitions samo gdje treba

Gdje implementirano:
- <img loading="lazy"> na svim slikama u galeriji
- touch-action: manipulation (sprječava delay)
- -webkit-tap-highlight-color: transparent
- Smooth scroll bez heavy animacija

-----------------------------------

✅ PRAVILO 10: CTA UVIJEK VIDLJIV NA VRHU
-----------------------------------
• Hero sekcija odmah na vrhu
• "Kontaktirajte nas" dugme vidljivo bez skrolanja
• Fixed navbar dostupan uvijek
• WhatsApp/Social floating ikone stalno prisutne

Gdje implementirano:
- Hero button vidljiv u prva dva ekrana
- .navbar { position: fixed; top: 0; }
- .fixed-social { position: fixed; } (desno dolje)
- Min-height hero: 70vh (pokriva većinu ekrana)

-----------------------------------

==========================================
DODATNE OPTIMIZACIJE:
==========================================

📱 Touch-friendly elementi:
   • user-select: none (sprječava slučajni select)
   • -webkit-tap-highlight-color: transparent
   • touch-action: manipulation

🎨 Accessibility:
   • Font minimalno 16px
   • Touch zone minimalno 44px
   • Kontrast > 4.5:1
   • Focus states na inputima

⚡ Performance:
   • CSS transitions umjesto JS animacija
   • Lazy loading slika
   • Background-attachment: scroll (bolje za mobitel)
   • Minimalni box-shadows
